The result, stated plainly

A 27B open-weight model, 4-bit quantized, running on a laptop, went head-to-head with Opus 4.6 on agentic work — and matched it task for task, including failing the same trap. Opus 4.6 is not a soft target: released February 5, 2026, it was the frontier — the model that made teams comfortable pushing model-written code to production, the release that turned "agents" from demo to default. Six months from frontier to running on a laptop in 18 GB. Matching it from 1/50th the parameters, offline, is a genuine feat. On this evidence, the community's excitement is not exaggeration. The honest caveats: 24 tasks, one eval family, both models at the ceiling — this shows the 27B clears the bar, not that they're equals everywhere. And the OG is no longer the frontier; today's bar is the Fable 5 / Opus 5 generation. Which is exactly why the trajectory below matters more than the tie itself.

Why this matters — the flip is coming

Every serious AI adoption today routes through an API bill. The day an open model delivers frontier-class agentic work on hardware you own, the economics invert: no per-token meter, no data leaving the building, no rate limits. This episode says that day is closer than the discourse thinks — a 27B already clears the bar that started the adoption wave. (And yes: buying the M5 Max before the memory price surge is aging very well.)

Fine print

  • Both at the ceiling — this suite says "both clear the bar," not "they're equal." n=24, 2 runs, no statistical power for ranking.
  • Keyword scoring is auditable but shallow; transcripts hand-spot-checked, not exhaustively.
  • Sampling not pinned across engines; 4-bit quantization only; mock tools never fail — recovery and injection-resistance untested.
  • Harness built with Claude's assistance; hard tier independently authored by Gemini, logic unmodified. Full tasks, mock world, and raw transcripts in the repo — audit everything.
  • Gotcha worth stealing: Qwen3.8 emits XML-style tool calls, not Hermes-JSON. My first run scored it 0 on a task it aced — the parser was wrong, not the model. Check your harness before you believe any benchmark.
